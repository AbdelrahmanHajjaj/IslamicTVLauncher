# What Afnon needs from the TV after `adb install`, one shell command per line. The one source for both
# tools/install.sh and the phone installer, which reads this file from the release's tag, so a new step here
# reaches every installer without updating it. Keep each command one line, safe to run again, and
# harmless on brands that lack the setting (end with "; true" when failing is fine).
#
# required|English label|Arabic label|command
1|Afnon is the home screen|أفنون هو الشاشة الرئيسية|cmd package set-home-activity tv.afnon.home/.MainActivity
1|Remote buttons and the call to prayer|أزرار جهاز التحكم والأذان|s=$(settings get secure enabled_accessibility_services); case "$s" in *tv.afnon.home/.RemoteKeys*) ;; ''|null) s=tv.afnon.home/.RemoteKeys ;; *) s="$s:tv.afnon.home/.RemoteKeys" ;; esac; settings put secure enabled_accessibility_services "$s" && settings put secure accessibility_enabled 1
0|Afnon screensaver|شاشة توقّف أفنون|settings put secure screensaver_components tv.afnon.home/.AfnonDream
0|Starts by itself after a restart|يعمل وحده بعد إعادة التشغيل|appops set tv.afnon.home APP_AUTO_START allow 2>/dev/null; appops set tv.afnon.home APP_ASSOC_START allow 2>/dev/null; true
0|Quran Radio level bars and sleep timer|مؤشّر صوت إذاعة القرآن ومؤقّت النوم|pm grant tv.afnon.home android.permission.RECORD_AUDIO && pm grant tv.afnon.home android.permission.WRITE_SECURE_SETTINGS
0|Wi-Fi name in Settings|اسم الواي فاي في الإعدادات|pm grant tv.afnon.home android.permission.ACCESS_FINE_LOCATION
