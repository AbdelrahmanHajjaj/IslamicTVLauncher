# Bundled phone setup. Existing screensaver choice is preserved. PC setup uses device.py.
1|Afnon is the home screen|أفنون هو الشاشة الرئيسية|am start -W -n tv.afnon.home/.MainActivity && cmd package set-home-activity --user 0 tv.afnon.home/.MainActivity
?|cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME | tail -n 1 | grep -q '^tv.afnon.home/'
0|Quran Radio level bars and sleep timer|مؤشّر صوت إذاعة القرآن ومؤقّت النوم|pm grant tv.afnon.home android.permission.RECORD_AUDIO && pm grant tv.afnon.home android.permission.WRITE_SECURE_SETTINGS
?|d=$(dumpsys package tv.afnon.home); echo "$d" | grep -q 'RECORD_AUDIO: granted=true' && echo "$d" | grep -q 'WRITE_SECURE_SETTINGS: granted=true'
1|Remote buttons and the call to prayer|أزرار جهاز التحكم والأذان|s=$(settings get secure enabled_accessibility_services); case "$s" in *tv.afnon.home/.RemoteKeys*|*tv.afnon.home/tv.afnon.home.RemoteKeys*) ;; ''|null) s=tv.afnon.home/.RemoteKeys ;; *) s="$s:tv.afnon.home/.RemoteKeys" ;; esac; settings put secure enabled_accessibility_services "$s" && settings put secure accessibility_enabled 1
?|settings get secure enabled_accessibility_services | grep -Eq 'tv[.]afnon[.]home/(tv[.]afnon[.]home)?[.]RemoteKeys' && [ "$(settings get secure accessibility_enabled)" = 1 ]
0|Starts by itself after a restart|يعمل وحده بعد إعادة التشغيل|appops set tv.afnon.home APP_AUTO_START allow 2>/dev/null; appops set tv.afnon.home APP_ASSOC_START allow 2>/dev/null; true
?|o=$(appops get tv.afnon.home APP_AUTO_START 2>&1); case "$o" in *allow*) true ;; *) false ;; esac
0|Wi-Fi name in Settings|اسم الواي فاي في الإعدادات|pm grant tv.afnon.home android.permission.ACCESS_FINE_LOCATION
?|dumpsys package tv.afnon.home | grep -q 'ACCESS_FINE_LOCATION: granted=true'
