RTL mirroring notes

العربية أولًا
Each screen is one layout with a locale switch. The switch flips dir and nothing else: every position is a logical property (inset-inline-start, padding-inline, text-align: start), so Arabic is the same design mirrored, not a second design.
MIRRORS
  • The arch sits on the start side: right in Arabic, left in English. The courtyard takes the other side.
  • Prayer cells run Fajr → Isha from the start edge; favourites start with YouTube at the start edge.
  • D-pad: in Arabic ◀ means next and ▶ means previous along a row. The focus map swaps every Left/Right.
  • Back chevrons, "more" chevrons and the "All apps ←" arrow flip.
  • Reminder toast and the Inputs panel come from the end side (left in Arabic). The over-video banner sits top-end.
  • Segmented controls list options from the start; a toggle's "on" knob sits at the end side.
  • The banner timer line drains toward the start side.
NEVER MIRRORS
  • Times and countdowns: hours:minutes keep their order (١٤:٢١, never ٢١:١٤). Wrap them in a Unicode isolate and use tabular figures so the countdown doesn't jitter.
  • The Qibla compass and its 136° bearing are geography; north stays up.
  • Media glyphs (play, volume) and the video progress bar of other apps.
  • Latin names inside Arabic — Claude Code TV, BrowseHere, Home-WiFi, HDMI — are isolated as LTR runs.
  • The arch shape and the star lattice are symmetric, so they need no flipped asset.
  • Sacred text is always Arabic, RTL and in the arch's crown, in both languages; in English it gets a reference line, not a translation inside the crown.
Digits are their own setting
Eastern Arabic (٠١٢٣) is the default in Arabic, but it is a separate switch: Arabic with Western digits and English with Eastern digits both work.
Arabic type
Never letter-spaced and never set in caps-style tracking. Line height 1.5 or more where diacritics appear. Amiri 700 for display, Alexandria for UI.
Same focus, both ways
On Home the default focus is the arch in both languages; the focus ring, scale and fill do not change with direction.
