# Historical upstream contribution planning

This document's earlier proposals and permissions are superseded. Git history
retains the full plan; it grants no current permission to push, submit upstream,
merge, release or administer repositories.

Islamic TV Launcher now maintains its own architecture and contribution workflow:

- [CONTRIBUTING.md](../CONTRIBUTING.md): contributions target this project's `main`.
- [TESTING.md](../TESTING.md): required checks and evidence by changed boundary.
- [ARCHITECTURE.md](ARCHITECTURE.md): implemented core/platform breakdown.
- [ARCHITECTURE-QUEUE.md](ARCHITECTURE-QUEUE.md): current scope, acceptance and next action.
- [REPOSITORY-INDEPENDENCE.md](REPOSITORY-INDEPENDENCE.md): prepared fork detachment
  and retained attribution, history and installed identities.

The original Afnon and CleanYourTV credits/notices remain in the README, root
licence and third-party material. Future upstream contributions need their own
explicit scope; they are not the default delivery path for this project.
